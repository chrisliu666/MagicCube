# MagicCube — 3D 魔方模拟器

一个基于 Three.js 的 3D 魔方模拟器，纯前端运行，无需任何构建工具或后端服务。

## 功能

- **3D 魔方** — 完整的 3×3×3 魔方，带黑色边框和真实颜色
- **鼠标拖拽旋转视角** — 左键拖拽旋转，滚轮缩放
- **鼠标直接拖拽转面** — 直接在面上点击拖拽即可旋转该面
- **手动逐面旋转** — 点击按钮或按键盘旋转任意面
- **自动打乱** — 随机打乱 N 步（步数可调）
- **自动还原** — 逆序执行打乱步骤，一键还原
- **键盘快捷键** — 双手不离键盘即可操作

## 线上快速开始

打开浏览器访问 `https://chrisliu666.github.io/MagicCube/`

## 本地快速开始

确保已安装 [Node.js](https://nodejs.org/) 或 [Python 3](https://www.python.org/)，克隆或下载本项目后：

```bash
# 方式一：Python
python -m http.server 8000

# 方式二：Node.js
npx serve .

# 方式三：使用 VS Code 的 Live Server 插件
# 右键 index.html → Open with Live Server
```

打开浏览器访问 `http://localhost:8000`。


> **注意：** 由于使用了 JavaScript ES Module，不能直接双击 `index.html` 打开。某些浏览器会因 CORS 策略阻止模块加载，请务必通过 HTTP 服务器访问。

## 操作说明

### 鼠标直接拖拽转面

直接在魔方面上点击并拖拽即可旋转该面，操作更直观。拖拽超过一定距离后自动识别顺/逆时针方向并执行旋转。

鼠标在魔方上悬停时光标变为 **手形**，拖拽时变为 **抓取**。

### 视角控制

| 操作 | 方式 |
|---|---|
| 旋转视角 | 鼠标左键拖拽 |
| 缩放 | 鼠标滚轮 |

### 键盘快捷键

| 按键 | 动作 |
|---|---|
| `r` / `R` | 右面 顺时针 / 逆时针 |
| `l` / `L` | 左面 顺时针 / 逆时针 |
| `u` / `U` | 上面 顺时针 / 逆时针 |
| `d` / `D` | 下面 顺时针 / 逆时针 |
| `f` / `F` | 前面 顺时针 / 逆时针 |
| `b` / `B` | 后面 顺时针 / 逆时针 |
| `s` | 打乱 |
| `z` | 还原 |

小写字母为顺时针，大写字母为逆时针（从该面外侧向中心看）。

### 按钮操作

屏幕底部控制面板：

- **面按钮（R / R' / L / L' 等）** — 逐面旋转
- **打乱步数输入框** — 设置打乱步数（5~100）
- **打乱** — 随机打乱魔方
- **还原** — 逆序还原魔方
- **重置** — 立即重置到初始状态
